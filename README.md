# Media Toolkit

Media Toolkit for WordPress

## Cel projektu

Media Toolkit jest rozwijaną wtyczką dla WordPressa, której pierwszym zadaniem jest zarządzanie dużymi obrazami oraz diagnostyka biblioteki mediów.

Projekt powstaje etapami.

## Roadmap

- 0.1 Foundation
- 0.2 Big Image Control
- 0.3 Diagnostics
- 0.4 Reports
- 0.5 Tools
